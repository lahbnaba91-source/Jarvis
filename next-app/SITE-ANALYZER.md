# Site Analyzer

A free, self-hosted "digital twin" tool: search an address, load its real 3D
buildings/terrain/roads, and get measurement + solar-analysis info useful for
builders, homeowners, and home-renovation/solar-siting decisions.

Lives at `next-app/`'s root route (`/`) — this app had no other pages, so it
became the home for this system.

## What it does

- **Search an address** (free OSM/Nominatim geocoding) and fly to it in 3D.
- **3D buildings + terrain** via Cesium ion's free-tier global datasets
  (Cesium OSM Buildings + Cesium World Terrain).
- **Roads** overlaid from OpenStreetMap (Overpass API).
- **Measurement**: click two points in the scene to get a real 3D distance
  (works for footprints, setbacks, wall/roof spans, etc).
- **Solar analysis**: a date + time-of-day slider drives Cesium's real
  astronomical sun position, casting actual shadows on the loaded geometry —
  drag through a day or season to see what gets shaded. The sidebar also
  reports sunrise/sunset/solar-noon altitude, and a rough sun-hours-per-wall
  estimate for the nearest mapped building (four wall directions, derived
  from its OSM footprint) — a fast first pass; the real shadow rendering
  above is the ground truth for actual obstructions.
- **Site report**: footprint area, height (from OSM tags or a levels
  estimate), and orientation for the nearest mapped building.
- **Shareable**: the URL encodes the current site/date/time — no backend or
  login, just send the link.

## Setup

```
cd next-app
npm install     # also copies Cesium's runtime assets into public/cesium (postinstall)
cp .env.local.example .env.local
```

Then get a **free** Cesium ion account at https://ion.cesium.com/signup,
grab a token from the "Access Tokens" tab, and put it in `.env.local`:

```
NEXT_PUBLIC_CESIUM_ION_TOKEN=your-token-here
```

Without a token the app still runs — address search, roads, and measurement
all work — but falls back to a flat OpenStreetMap basemap (no 3D
buildings/terrain/shadows, since those two datasets are ion-hosted).

```
npm run dev
```

## How it's built

- **Framework**: Next.js App Router, entirely client-rendered (`ssr: false`)
  since CesiumJS needs the DOM and the page reads its initial view from the
  URL on mount.
- **3D engine**: [CesiumJS](https://cesium.com/platform/cesiumjs/) — the
  purpose-built OSS tool for geospatial 3D (terrain, global building tiles,
  accurate sun position and shadow casting all ship with it).
- **Data**: Nominatim (geocoding), Overpass API (road + building footprint
  vector data from OSM), `@turf/turf` (footprint area/orientation math),
  `suncalc` (sun position/daylight astronomy).
- **Cesium's static runtime assets** (Workers/Assets/ThirdParty/Widgets) are
  copied from `node_modules/cesium` into `public/cesium/` by
  `scripts/copy-cesium-assets.mjs`, run automatically via `postinstall`.
  That folder is gitignored — it's regenerated by `npm install`, not
  committed.

## Known limits (MVP)

- Single-site focus — no city-scale browsing, no accounts, no persistence
  beyond the URL's own site/date/time.
- The "solar exposure by wall" numbers in the sidebar are geometry +
  astronomy only (no terrain/neighboring-building shading) — cross-check
  against the 3D scene's real shadow rendering for actual obstructions.
- Overpass and Nominatim are shared public instances — be considerate of
  request volume (both are free, rate-limited services).
